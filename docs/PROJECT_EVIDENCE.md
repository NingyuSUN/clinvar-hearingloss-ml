## Research question and approach

**How well does a variant classifier generalize to genes excluded from training?**

I combined ClinVar labels with VEP consequence annotations, allele shape,
gnomAD frequency and gene constraint, conservation and protein-domain features.
The headline model is XGBoost with 18 features. Feature ablation and out-of-fold
SHAP describe which inputs contribute to its predictions.

The eligible cohort contains 7,125 feature-complete variants with ClinVar review
status of at least one star: 3,576 pathogenic/likely pathogenic (P/LP) and
3,549 benign/likely benign (B/LB). VUS and conflicting labels are excluded.
Shared-gene connected components define 167 groups, kept together in five-fold
outer evaluation over ten fixed seeds. Inner training data determine imputation;
an inner gene-group holdout selects boosting rounds and the R90 decision
threshold. Outer-test genes do not participate in those choices.

## Results and the errors behind them

| Evaluation | Variants / gene groups | Pooled AUC [conditional 95% interval] | Missed P/LP | Flagged B/LB |
|---|---:|---|---|---|
| Gene-held-out headline | 7,125 / 167 | **0.930 [0.892, 0.974]** | **554 / 3,576 (15.49%)** | **513 / 3,549 (14.45%)** |
| Coding non-truncating dedicated model | 3,121 / 148 | 0.815 [0.702, 0.920] | 89 / 989 (9.00%) | 813 / 2,132 (38.13%) |
| Random-row split diagnostic | 7,125 / 167 | 0.996 [0.994, 0.998] | 338 / 3,576 (9.45%) | 22 / 3,549 (0.62%) |

AUC measures ranking, not the percentage of correct clinical diagnoses.
The headline operating rule retrieves **3,022 / 3,576 P/LP variants
(84.51% recall)**. Of its 3,535 positive calls, **3,022 match P/LP
(85.49% precision)**. Selecting a threshold for 90% recall on inner validation
does not guarantee 90% recall on unseen genes.

The coding non-truncating cohort includes synonymous variants and is not strict
missense. Its dedicated model's recall is 900 / 989 = 91.00%, with precision
900 / 1,713 = 52.54%. The headline model's recall on that same subgroup is
reported separately as 0.530; these are different fitted comparisons.

Each variant has one outer-test prediction per seed. AUC uses its ten-seed mean
score. Classification first applies each seed/fold's own threshold, then votes
across ten calls; five-to-five ties are positive. The error counts above are
unique-variant integers, not averaged counts or performance of a single deployed
model.

Intervals resample whole gene groups 2,000 times while keeping predictions fixed.
They exclude retraining, model-selection uncertainty and full cross-validation
dependence. They supersede the historical, narrower variant-row intervals.
The coding non-truncating change from 0.814 to 0.815 reflects reporting the
empirical estimate instead of the bootstrap mean; it is not a model improvement.

## Research inference delivered

The CLI packages five configurations: original 18 features, three GPN scores,
their combination, and two configurations adding composite AVI information
(unified or consequence-stratified). GPN and AVI are existing pretrained/model
outputs integrated into this project, not foundation models trained here.
AVI combines AlphaGenome, AlphaMissense and related signals.

Frozen cached inference supports 4,050 of the 7,125 development variants.
Unsupported inputs retain null scores and explicit reasons; bundle hashes are
checked before use. This is an inspectable research demonstration, not an
external test on novel variants. Its fixed seed101 prediction profile is separate
from the repeated-CV headline evaluation above.

Experimental live annotation currently permits **GPN3 only**, when identity,
consequence, gene mapping and all three scores pass validation. The four models
requiring the unresolved original conservation feature remain blocked.
UCSC phyloP is reference-only and is not substituted into those models.
All scores are uncalibrated, not probabilities of pathogenicity.

## How to verify the work

From a checkout of the pinned version, the standard-library artifact check is:

```bash
python tools/validate_public_artifacts.py
```

It checks artifact structure and consistency; it does not establish scientific
validity or re-estimate AUC.

The frozen CPU inference example requires Python 3.11+ and the listed inference
dependencies. Choose a new output directory:

```bash
pip install -r predict/requirements-inference.txt
python predict/predict_variants.py --input predict/examples/input.csv --bundle predict/bundle --output demo_output/
python predict/render_variant_report.py --predictions demo_output/predictions.jsonl --variant-id 48
```

This runs saved models without new training or live annotation. Full statistical
reproduction of the revised intervals additionally needs archived per-variant
out-of-fold predictions, which are not shipped in the public repository.
The public [training instructions](../README.md#evaluation-and-reproduction)
instead rebuild the evaluation from the committed modelling matrix.

[Historical CI success for the pinned commit, 24 September 2026](https://github.com/NingyuSUN/clinvar-hearingloss-ml/actions/runs/35964717005)
covers repository tests and the frozen inference demo; it is not a new execution
for this documentation update.

## Remaining research boundaries

Independent external labels, probability calibration and conservation-feature
provenance remain unresolved. Allele frequency contributes to both the classifier
and some ClinVar classifications, so gene holdout alone does not remove evidence
circularity. Pretrained-score overlap and hearing-loss-specific label attribution
also require further audit. SHAP and ablation are descriptive evidence, not
causal or clinical validation.
